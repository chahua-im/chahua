# 转发 picker 修复计划

用户授权：修复全面审查发现的全部问题；先落盘，再逐项实施。此文件记录执行进度，产品约定仍归属 `pwa/docs/`。

## 范围与基线

- PWA `ForwardPicker`、共享聊天/话题查询、转发导航、头像和相关文档/测试。
- 不修改发送协议，不增加全量历史扫描，保留缓存复用、独立数据源、失效来源校验和转发草稿语义。
- 基线：相关 6 个测试文件共 311 项通过；手机 390×844 和桌面 1280×900 Chromium 使用模拟网络复现问题。
- 审查脚本和日志：`/tmp/chahua-picker-audit.mjs`、`/tmp/chahua-picker-audit-desktop.mjs`、对应 `.log`；旧构建 `/tmp/chahua-picker-audit-build`。这些是审查工具，不是产品依赖。
- 测试必须拦截 HTTP、WebSocket、上传及外部网络，禁止生产写入。

## 实施顺序

1. 生命周期、导航和移动布局（1–3、14）。先补取消与真实弹窗/路由失败回归。
2. 查询错误/重试与 picker 加载、搜索反馈（4–11）。保持其他查询消费者兼容。
3. 列表滚动/按压稳定性和头像（12–13）。使用组件局部实现，不引入通用框架。
4. 更新 requirements、data-flow、components、appearance、loading-indicators 的当前约定；中文简繁及英文文案保持齐全。
5. 运行针对性测试、构建及拦截网络的移动/桌面浏览器验证；检查完整改动，记录结果。

## 验证矩阵

- 冷启动/缓存重开、聊天和话题先后返回、已有数据刷新、单侧失败/重试、断线重连。
- 空列表、部分搜索无匹配、全量无结果、长列表搜索、分页/搜索交叉、连续触底、手动与触底并发。
- 慢速来源读取、重复选择、取消按钮/遮罩/关闭动画、组件销毁、来源撤回、路由失败/成功/同路由。
- 手机长列表底部、桌面、跨断点、搜索展开、模拟可视区域变小；原生软键盘/手势需要真机，不将模拟验证宣称为真机验证。
- 排序更新、延迟插入、阅读锚点、按下目标后实时变化、权限撤销不被延迟恢复。
- 头像加载成功/失败/URL 切换、主题及尺寸稳定。
