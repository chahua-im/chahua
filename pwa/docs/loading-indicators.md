# 加载与操作反馈

加载图标不搭配文字。需要展示的错误提示和重试入口使用文字；归档计数与好友请求加载失败保持静默，见[聊天列表约定](requirements.md#聊天列表)。未知进度使用 Ionic circular spinner，附件处理与上传使用确定性圆形进度环；加载状态不等同于禁用整个输入区或页面，具体提交规则见[需求](requirements.md#输入草稿与待发队列)。spinner 只表示内容或动作正在返回，持续性的连接状态和空闲控件不使用 spinner。

后台更新检查无加载提示，不阻塞 Angular 或登录。业务页面的新版就绪 toast 不自动消失，提供“立即更新”和“暂不更新”；启动失败或 landing 时按[更新约定](requirements.md#通知静音与设置)自动刷新。

主列表固定显示“已归档”，好友 tab 还显示“好友请求”历史入口；入口立即可用。首次内容加载时 page-loading 是入口下方的居中加载块。归档数字独立更新，历史数据在进入对应页面时读取。

切换分类时，当前分类的列表查询结束后统一展示内容，已有缓存且未失效的分类直接展示；固定入口和归档统计不参与等待。首次展示完成后的刷新保留原列表。

对话分页控件外层按钮提供固定点击区域。可分页时控件常驻：空闲显示上下箭头图标且可点击，加载时替换为 Ionic circular spinner。自动预取在接近边缘时发生，历史消息在触摸与惯性结束后合并；首条可见消息的底部位置是滚动锚点。

对话首次加载时，若已有待发送消息，消息骨架屏显示在待发送消息上方。

## 加载失败

页面或区块加载失败时使用共享的 LoadError：图标、说明和“重试”按钮。页面级失败在内容区居中，列表、信息栏和设置分区使用紧凑行；不可重试的错误（消息已删除或无法查看）不显示按钮。操作失败仍使用原位文字或 Toast，不换成整块失败页。

列表、消息和表情面板的整体骨架屏只用于首次内容加载：占位块与真实行/气泡/贴纸同尺寸，浅色脉动，不用 shimmer 扫光。切换分类在骨架屏与已缓存内容之间二选一；刷新、续页和已有内容的加载不显示整块骨架屏，仍使用 Ionic 自带指示器。表情面板只在没有可展示的贴纸时使用骨架块，切换表情包保留现有内容。

在线状态的紧凑线框只占预留状态行，不替换名称或整个信息头部。单个媒体（含相册中的每一格）在自身就绪前另行覆盖骨架块，加载失败时同样移除；拉伸铺满气泡的图片仍以原有模糊底色作为占位。

收藏、表情收藏和表态不使用加载图标，成功由 Toast 确认，请求失败时回滚取值并提示。消息收藏状态读取期间按钮仍可点击：菜单立即关闭，等待读取完成后按点击时显示的「收藏／取消收藏」执行，读取失败则提示失败，不提交写入；状态已知时乐观更新。表情收藏和表态在菜单关闭后立即生效。收藏的菜单文案随当前状态在「收藏／取消收藏」和「收藏表情／取消收藏表情」之间切换。

图标切换为 spinner 时，两者使用相同宽高；Ionic 纯图标按钮在两种状态下都保留 `icon-only` 槽位，避免按钮尺寸变化。`.action-icon` spinner 使用主题正文色，不继承图标按钮的蓝色。

操作按钮通过 `.action-content` 和 `.action-label` 保留原有尺寸，spinner 绝对定位叠放。`.busy` 控制原内容的隐藏，spinner 显示等待状态。

消息菜单确认框、Toast 与菜单开关属于 MessageMenu；页面读取其 busy 用于 toolbar。页面离开会清理提示并使旧操作的 UI 收尾失效。数据请求时机见[数据流](data-flow.md)，组件边界见[组件](components.md)。

输入区不因消息读取、发送或编辑请求进入忙碌状态。编辑保存后在原消息上显示队列状态，失败原位重试；尚未发出的消息编辑直接更新该行。撤回立即隐藏消息，网络请求由队列继续处理。录音能力不足时显示 mic-off-outline，点击展示 Ionic alert，不使用禁用按钮。

通知设置菜单等待用户选择；确认后立即更新静音标记，会话标题栏保留新图标并禁用重复点击；失败回退，取消菜单不发送请求。静音到期只更新标记和计数，不显示全屏 loading。通知横幅不改变页面加载状态，点击后复用会话页面已有的消息定位反馈。

资料的成员、话题、媒体与聊天搜索使用 IonInfiniteScroll，加载标识与 ChatList 一致，不提供可点击的加载控件。有下一页时保留 Ionic 默认 84px 加载区域与 spinner 节点，空闲时仅隐藏 spinner；末页或出错时收起加载区域。首次读取使用 page-loading；触底续页只显示 Ionic 的 spinner，不同时显示局部 spinner。续页请求结束后调用 complete；错误重试重新挂载控件，不沿用失败前的触底状态。成员、媒体和聊天搜索不足一屏时继续补页；话题只在触底时续页，不自动扫描普通消息填满侧栏。连接状态不在 toolbar 上显示；离线的影响由消息发送状态承载（排队 time-outline、失败原位重试），不增加连接指示控件。

VoicePlayer 首次播放与缓冲时在圆形按钮内显示 spinner，波形读取失败不阻止可用的音频播放；吸顶播放条的播放按钮与气泡同步显示 spinner。贴纸上传的等待留在贴纸面板；邀请卡片的加载保持固定高度。私聊关系不可发送时点击提交显示原因，输入内容保持可编辑。

用户资料的 busy 只表示主动操作；共享好友关系读取不隐藏已知资料，未取得关系时暂不允许好友/拉黑操作。点击添加好友才读取验证方式，原按钮显示 spinner；取消确认不发送好友请求。

附件任务只暴露一个 0–1 总进度：照片入口的压缩占 0–50%，上传占 50–100%；压缩完成切换到上传时不归零。无需压缩的普通文件与语音按上传字节显示 0–100%。已完成压缩的重试直接从上传阶段开始；新一轮传输按实际字节重新计算。输入栏和已上屏附件共用这一进度，圆环尺寸固定，不随进度改变布局。

## 转发反馈

选择目标只准备转发草稿并导航，不显示“正在转发”提示。目标会话输入框显示选定时的待转发预览，不跟随源消息变化。点击发送后清除预览及附言输入，转发显示为待发消息；服务端确认成功后附言独立入队，来源不可用则显示失败且不发送附言。后端报告占位需求时弹窗确认，同意后继续提交，取消保留失败任务及未发送附言供重试。发送状态和失败重试沿用普通消息。

目标选择器首次无原始数据时居中显示 spinner；已有目标刷新时保留列表，搜索没有匹配项不触发整块加载态。另一来源尚未首次返回或用户主动重试时，在列表后的固定高度状态区显示局部 spinner；普通后台刷新保持静默。分页使用 IonInfiniteScroll，并保留“继续加载”按钮供内容不足一屏时使用；手动加载在按钮内显示 spinner、保留文案尺寸，触底加载使用底部 spinner，两种反馈互斥，分页期间禁用按钮。聊天和话题的目标读取失败分别显示紧凑重试行，未读错误不影响目标选择与分页；重试期间已加载目标仍可选择。

点击目标只准备一次转发草稿，在所选行的固定尺寸区域显示 spinner，暂时禁止重复选择；来源读取期间取消仍有效。导航失败提示后原位重新选择，成功才关闭弹窗。固定选择失效时保留目标列表并禁用提交，原位提示关闭后重新选择。话题整体转发在选择目标时读取当前消息，超限、包含不可转发消息或读取失败均仅使用 Toast 提示，不重复添加顶部错误，保留目标列表供重试。

聊天记录详情首次读取显示 spinner，失败显示重试；后台校验和临时失败保留现有消息，授权失效时清除消息并显示无法访问提示；主时间线只使用已有卡片预览，不为详情预加载显示 spinner。

多选批量撤回期间，底栏撤回图标替换为 spinner，勾选和底栏按钮禁用；已入库但尚未发布的语音在等待发布期间也保持处理状态；仅服务端确认撤回后增加成功数量。结束后 Toast 显示撤回数量，等待超时或请求失败时同时显示失败数量并保留未撤回项供重试。

尚无服务端 ID 的本地消息禁用勾选且菜单不提供多选或转发；取得 ID 后自动可选，不等待语音发布。勾选期间不根据转码状态或合并嵌套限制禁用消息和转发按钮；选择目标前发现来源失效或类型不支持时提示并阻止准备草稿。进入目标会话后，来源是否可用及占位需求均由发送接口判断，反馈见本节转发队列规则。

隐私首页四条入口常驻，初次摘要加载时仅在对应行右侧显示 spinner，各请求独立完成。失败不显示“无”或默认权限，对应行右侧以小字显示“加载失败，点击重试”；点击失败行只重试该项，不打开详情。拉黑列表初次显示列表内 spinner，空列表确认后显示“无”，失败使用紧凑 LoadError。

语言切换等待期间禁用选项并显示 spinner，失败显示重试行。创建贴纸包期间入口禁用并显示 spinner；贴纸包详情写入期间在工具栏下方显示不定进度条。排序保存中禁用拖动并显示 spinner，失败显示原位重试按钮。

通知分类默认开关保存时保留乐观取值并禁用重复提交，失败回退并显示错误；新的多端状态优先。例外初次读取在分类内显示 spinner，刷新和续页保留已有行及总数；未读取成功不显示零。恢复默认按钮保留文案尺寸并叠放 spinner，失败保留原例外并允许重试。

通知首页摘要计数首次加载仅占据副标题中的固定 spinner 空间，刷新保留上次完整总数。删除所有例外确认期间禁用分类内例外操作，成功后刷新真实列表，失败保留列表并提供错误提示；选择器保存失败保留当前选择列表。
