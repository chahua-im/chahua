# 产品需求与边界

本文是交互要求的统一入口。只描述当前约定，不记录改动过程。具体尺寸见[外观](appearance.md)，请求与一致性见[数据流](data-flow.md)，字段归属见[组件](components.md)，等待状态见[加载与操作反馈](loading-indicators.md)。

## 范围

- 使用后端定义的协议；在线状态与群人数使用服务端授权的实时快照，不由客户端推算。生成的服务、模型不手动改名。
- 保留 `chats`、`conversations`、`messages` 三个关注范围；组件、局部工具与共享状态按实际职责划分，不为每个接口创建服务。
- Snowflake ID 的无损 number 编码是性能选择。可选字段允许运行时 `null`，不全量转换为 undefined；两处清除字段的特殊语义见[API 边界](data-flow.md#身份协议与入口)。
- 不提供 OOBE/欢迎引导、主动添加群成员。`/landing` 是安装页，保留旧版五个平台的安装指引、文案和样式；普通浏览器中页面只同步保存 token，不执行异步登录或邀请预览；已安装 PWA 由路由 guard 同步重定向到 `/chats`。
- 所有路由静态导入；表情选择器、媒体编解码等非路由资源可以按需加载。

## 启动、布局和导航

- App 同步读取 token 后，所有页面（包括 landing）在无 token 时直接显示无应用外壳的 418；有 token 但用户信息尚未加载时显示正常登录等待状态。

- 登录同时保存 localStorage 和 Cookie，兼顾长期保留与安装时传递；读取顺序、续期与失效处理见[身份数据流](data-flow.md#身份协议与入口)。URL token 读取后从地址栏移除。真实 token 不提交仓库，生产构建不注入开发预设。
- Angular 挂载前与登录期间的 spinner 外观一致，不带文字；登录期间显示无标题的空 toolbar，spinner 在内容区居中。
- 页面级加载失败居中显示图标、说明和“重试”；列表、信息栏与设置分区使用紧凑失败行。不可重试的错误不显示按钮；操作失败继续在原位提示或使用 Toast。
- 聊天列表和会话的首次内容加载使用与真实内容同尺寸的骨架屏；切换分类、刷新和续页不使用骨架屏。
- `md`（768px）起显示 384px 聊天列表侧栏；`xl`（1200px）起可显示右侧 360px 信息栏。较小屏幕以信息按钮打开 modal；两种信息容器均没有 toolbar。
- 单列进入/返回会话、归档和好友请求历史使用 Ionic 默认 iOS 页面动画与仅显示箭头的返回按钮；会话返回在 Ionic 页面栈有前序页面时按浏览器历史逐层退出，与滑动返回一致；直接进入且没有前序页面时，话题返回所属聊天，普通会话返回聊天列表。Safari 已提供可视返回动画时避免重复播放。分栏会话不显示返回按钮；从群聊进入话题时显示返回按钮并回到所属群聊的根消息位置，从聊天列表直接打开话题时不显示。
- 单列会话 toolbar 优先直接排列搜索、静音或话题订阅、信息；话题消息总数（含根消息）不超过 100 条时，在搜索前显示转发。标题无法完整显示时收进竖排三点按钮，点击向下弹出带图标的纵向操作菜单。`md` 起始终直接排列。
- 点击 tab 保留 Ionic 原生 segment 指示器，内容只让起点和终点横移一页宽度，不经过中间分类；只有下方内容移动，toolbar 不飞入。内容区禁止左右手势切换，保留列表项自身的左右滑动操作。四个 tab 各自保留滚动位置，仅当前 tab 激活列表分页查询，tab 计数共享汇总查询。
- 分栏时切 tab、归档和请求历史只改变左侧选择，不改变右侧会话路由或关闭会话。
- 点击头像向下弹出菜单，依次为我的收藏、设置、安装应用；收藏打开现有收藏页。仅收到浏览器 beforeinstallprompt 事件时显示安装入口，点击直接调用浏览器安装提示并隐藏入口；安装完成后也清除入口，只有收到新的安装事件才重新显示。不支持安装或证书等安装条件不满足时隐藏，不显示兜底 toast。设置及其子页、用户资料、会话详情、邀请、搜索、贴纸详情、表态详情和媒体查看均增加对应路由历史；浏览器右滑/返回逐层退出，离开路由会关闭对应弹窗，前进可重新打开。进入这些页面保留底层会话的消息、滚动位置和未发送内容。
- 手机页面禁止浏览器双击、双指缩放，媒体查看器保留自身的图片缩放。
- 移动端键盘弹出、收起或改变高度时，由浏览器处理可见区域和输入框避让；会话标题栏保持在可见区域顶部，编辑消息时仍可识别当前会话。应用不按键盘高度主动缩小或平移根页面。消息区继续使用原生滚动，不通过全局禁止 touchmove 或反复写入 scrollTop 纠正页面。
- 字号和控件密度按操作系统区分，不按是否有触屏或 hover 能力区分；窗口宽度只决定分栏。手机和平板系统使用移动密度，Windows 接触屏仍使用桌面密度。

## 聊天列表

消息、群组、好友与话题 tab 显示后端统计的未静音未读会话数；存在未静音的未读 mention 时改为显示 `@`，两者均为零时隐藏 badge。消息 tab 按“在消息中显示话题”选项包含话题数。各 tab 的 `@` 和未读数使用相同会话集合的服务端完整汇总，通过 WS 持续同步，不用已加载分页推算。

静音群聊的行内 `@` 保留并显示灰色，包括选中行，但不触发 tab 或后台标题的 `@`。话题按自身归档状态显示灰色，不继承父聊天静音。静音不清除未读；集合原始总数仍包含静音会话，tab badge 和列表标题排除静音会话。

| 场景                             | 分页与呈现规则                                                             |
| -------------------------------- | -------------------------------------------------------------------------- |
| 消息 tab，开启“在消息中显示话题” | 对话与话题分开请求，只显示两边共同覆盖的时间范围，触底补覆盖较浅的一侧     |
| 消息 tab，关闭该选项             | 只依赖普通对话分页                                                         |
| 群组、好友、话题独立 tab         | 独立分页，不做跨来源时间截断                                               |
| 初次显示或切分类                 | 等当前分类所需列表查询齐备后统一显示行，不能先露出部分缓存行再插入另一来源 |
| 刷新已有列表                     | 保留原内容，刷新结果齐备后替换                                             |
| 已归档、好友请求历史入口         | 常驻且立即可用，历史内容进入时读取；独立计数不阻塞列表                     |

- ChatList、成员及其他 IonList 的末项不显示底部分隔线，分隔线只用于区分列表项。
- 归档入口使用当前 tab 对应归档集合的未读消息总数，群组和好友分别统计，不遍历已加载的归档分页。“已归档”的角标为灰色。
- 归档计数与好友请求加载失败时静默保留已有数据，不显示错误行或专用重试按钮，等待下次正常更新。
- 请求历史包含除 pending 外的请求，包括 archive、accept、reject；入口不依赖历史是否为空或读取成功。
- 预览中的作者与系统行为使用主题蓝色，用户正文统一灰色；系统消息整条为蓝色。提及直接消费消息中的名字，显示不等待额外用户查询。
- 聊天列表、草稿、回复、置顶、话题与转发卡片的单行消息摘要将换行替换为空格，避免前后文字连在一起；Markdown 摘要保留格式并将块结构展开为单行。
- 草稿在保存时参与排序，不随每次输入重排列表；不为未加载的聊天凭空创建草稿行。
- 日期按应用语言的日历和地区格式显示：当天及跨午夜不足 8 小时用 HH:mm，前 1–6 天用短星期，365 天内其他日期用月日格式，更早用 shortDate；格式随语言设置切换，不随系统语言。不使用 time-ago 或每行计时器。
- 真实私聊列表项的头像右下角在对方在线时显示绿色圆点；消息、好友及归档列表中的私聊规则一致。群组、话题、好友请求和固定入口不显示圆点；离线、未知或无权查看时不显示，不增加灰色离线标记。在线定义与资料状态见[在线状态与最近上线](#在线状态与最近上线)。
- 加号菜单包含搜索入口；开启后 toolbar 变搜索条。协议支持群/用户目录搜索，不将它称为全局历史消息搜索。
- 连接状态不显示在列表和会话 toolbar 上，也不使用 spinner 表示连接；离线的影响由消息队列状态呈现（排队 time-outline、失败 alert-circle-outline 原位重试），恢复后自动续发。

## 会话阅读与滚动

- 从群消息的回复入口进入话题后，返回群聊复用原消息及头像节点、保留滚动位置；不先清空列表再重新加载。
- 普通聊天没有未读时进入最新位置；较长未读区间定位未读边界并显示“未读消息”，短尾部可直接贴底。话题缺读状态时以根消息为起点。显式消息链接、引用与置顶优先定位目标；页面内定位沿用 `#msg=消息ID`，也接受已有 `?message=消息ID` 链接；复制消息生成旧版 `/m/` 短链接，保留聊天和消息 ID 的无损编码。
- 未读分隔线以进入页面时的已读位置为边界，只落在他人发出的已确认消息前；不随阅读进度移动，撤回后移到下一条符合条件的消息，已撤回的话题根墓碑行不参与。
- 下箭头在离开最新位置或存在引用返回点时出现，优先返回引用来源，再回到实际未读的起点，最后是最新。未读起点与角标同源，取自共享读状态，不采用屏幕上进入时冻结的分隔线。未读数使用共享读状态；提及与表态提供独立跳转按钮，保留本次会话尚未跳转的目标。
- 普通 DOM 双向分页；接近边缘预取，触摸和惯性结束后合并历史。以可见消息底部为锚，不用每帧写 scrollTop 的循环纠偏。
- 顶部/底部分页控件空闲显示向上/向下箭头，加载时换成 spinner，不配文字。可分页时保留固定尺寸，避免图标切换改变滚动区域；具体交互见[加载反馈](loading-indicators.md)。
- 图片、视频、贴纸、邀请卡片和语音在资源完成前预留尺寸；引用摘要单行省略，不因名字或媒体晚到而改变高度。
- 消息和置顶独立读取，不能用“先置顶、后消息”的串行加载保证稳定。唯一一条置顶的新增/删除会改变栏位高度，因此等待手指松开且惯性结束再显示/隐藏；已有置顶栏内的内容更新立即显示。
- 置顶栏变化后，最新区间保持贴底，历史阅读保持消息屏幕位置。浮动日期与底部按钮保留 DOM 节点，显隐不重建滚动内容。浮动日期与正文日期相交时避让，同一天不重复显示；停止滚动后保留 1 秒，再用 200ms 向上淡出。
- Ionic 缓存页面完成离开时停止读取和滚动处理、释放未提交媒体资源；群聊被其话题覆盖时保留区间与节点，其余会话释放连续区间。应用级草稿和待发队列仍保留。
- 重连只做有限补读，不遍历历史补齐所有编辑、撤回、表态。一致性以旧版可用程度为边界，不引入完整同步日志或离线消息数据库。

## 消息外观与操作

- 会话、话题、置顶和合并转发记录的正文日期与浮动日期，以及收藏的原消息来源日期，共用消息日期规则：本地日历的当天显示“今天”、前一天显示“昨天”（跨年也优先使用昨天）；今年其他日期省略年份，其他年份保留年份。语音播放栏使用同一日期规则并附加 HH:mm；消息气泡（含搜索结果、媒体、收藏与转发）只显示 HH:mm。日期按应用语言格式化，视图检查时重新判断日期，不为消息逐行添加计时器；聊天列表采用[聊天列表](#聊天列表)中的紧凑规则。

- 正文支持 `**加粗**`、`__斜体__`、`~~删除线~~`、`||剧透||`、反引号行内代码及反引号围栏代码块、无序/有序列表和 HTTP(S) 链接。加粗与斜体可按任意顺序嵌套；引用块（行首 `>`）、单星号斜体、三星号粗斜体及波浪号代码围栏不作为语法解析。双字符格式标记保留已有的内侧空格外移规则。正文与摘要中的提及名称作为普通文字插入，不参与 Markdown 解析。
- 普通正文保留每次换行、连续空行及换行旁的空格，不因包含格式标记或链接而改用 Markdown 段落间距；行末反斜杠保留为文字。粗体、斜体、删除线与剧透可跨普通换行和空行，但不能跨列表项或代码块边界。
- 列表支持行首的 `- `、`+ `、数字序号及缩进嵌套；列表项续行需保持该项的内容缩进，未缩进的正文结束该项。列表项内部、项目之间及列表和代码块前后的空行按输入数量保留，不使用紧凑／松散列表的额外间距。反引号围栏优先作为代码块识别，支持语言名，内部保留空格、缩进、换行和原始标记，不解析列表、格式或提及；行内代码同样保留内部空白和换行。
- 消息链接仅在与当前页面同源且属于应用页面路径时通过 Router 打开，保留查询参数和片段；其他链接保留浏览器导航。同源判定包含协议、域名和端口，不使用域名别名白名单。Ctrl/Cmd/Shift/Alt 点击保留浏览器默认行为，预览中的链接保持不可操作。
- 正文中自动识别的裸 URL 允许在字母之间断行，减少长地址造成的行尾留白；带自定义文字的链接按普通文本换行。断行不修改地址或显示文字，不插入空格或零宽字符；代码块保留横向滚动，单行摘要保持省略。

- 同一天、同一作者的连续消息紧凑分组，系统消息打断分组；作者信息在组首，头像与尾巴在组尾。“显示全部头像”偏好仍有效，头像显隐不改变组内间距。私聊默认显示双方头像和用户名，可用「在私聊中显示双方头像和用户名」偏好关闭，关闭时头像列一并收起、气泡移到边缘；群聊不受该偏好影响。
- 普通消息的头像和用户名行均打开发送者资料；系统消息中的操作者用户名作为链接打开同一资料页，正文中的提及保留自己的资料入口。列表及引用摘要保持不可交互；邀请／移除对象只有名字而无 UID 时保持文本。
- 用户名与气泡引用的作者色沿用旧版明暗调色板及**用户名 hash**。这与 UID 不同，改名可以改变颜色；用户组颜色来自后端。用户组行高为 1.4。
- 气泡引用为两行：作者半粗、正文常规，作者色竖边与浅背景，正文省略。字号小于正文，不与回复输入栏共用高度。引用目标被撤回后整块引用不再显示；引用目标编辑后引用内容跟随最新内容，不依赖重新读取。
- 回复输入栏第一行显示“正在回复 xxx”；灰底、正文置灰，用户名及普通竖线为 primary 色，不使用用户色。上下两部分高度一致；竖线与 iOS 输入光标起点对齐，右侧 × 与下方贴纸图标对齐。
- 桌面仅整行 hover 时显示回复按钮；移动系统左滑显示右侧回复图标，相对气泡竖直居中，不计表态高度，随拉动填充，到阈值放大。纵向滚动不触发回复。
- 长按/右键打开表态和 actions，操作网格每行最多 5 项，不足 5 项时按实际按钮数量收窄，行数随可用操作数量变化，最多保留两行，可用操作超过 10 项时用末格箭头翻到第二页，最多 18 项，不预留空行。预览及面板不因权限、置顶或好友关系读取晚到而先展示错位布局。消息预览、表态条和操作面板之外的空白均可点击关闭，包括三块内容之间及两侧的透明区域。撤回动作使用红色。
- 操作依次为回复、话题、复制、转发、编辑、收藏（贴纸为收藏表情）、多选、查看表态、链接、置顶、撤回；私聊不提供链接，私聊双方都能置顶而群聊限管理员，好友关系失效（解除好友或任一方拉黑）的私聊只保留复制、转发、多选、收藏和查看表态，且由服务器拒绝表态，菜单内的表态点击只关闭菜单、不发送请求。
- 菜单中的消息固定显示气泡尖角和头像；除贴纸和聊天记录卡片外，固定显示用户名，不沿用连续发言的省略状态，不允许滚动预览。补出用户名时向上展开，按可用宽度加宽预览，保持正文原位。消息横向位置在有空余时保持不变；补出头像列后接近屏幕边缘时预览整体横移，避免头像被裁切。表态与操作面板各自避让屏幕左右边缘。三块内容高度能放下时，仅为避开上下边缘平滑移动；放不下时消息正文保持原位，两块菜单靠近点按位置显示，底层聊天滚动位置不变。
- 移动端第一次长按消息打开菜单，再长按菜单中的消息正文可用系统原生选词和复制；图片说明文字遵循同一规则。预览中的引用、媒体、提及和链接保持不可操作。
- 表态独立显示在消息主体下方，消息头像和桌面回复按钮与气泡底部对齐，不随表态区域下移；表态包含用户头像，胶囊造型与 main 分支一致，可查看完整名单并按表情切换；最近表情跨会话保存。快捷表态行以置顶表态表情在前、最近使用去重补足，最多 5 个；已置顶的表情不再进入最近使用。添加或取消表态时，本地立即更新数量、个人选择和自己的头像；个人资料取自当前 SessionStore，后续广播更新服务端统计与头像名单。
- 表情选择器使用 @nicematic/emoji-picker 的搜索输入、连续分类列表和最近使用区，覆盖 Unicode 17 的完整分类数据；支持英文、简中、繁中名称与关键词搜索，以及粘贴完整表情查找。普通肤色通过长按选择，混合肤色组合在分类列表中独立展示；选择和最近记录保留准确的 Unicode 序列。最近使用在本机保存最多 10 条，沿用组件的频率与时间加权排序，和消息菜单的 5 个快捷表态独立。消息表态和设置内的置顶表态选择共用该选择器。消息菜单内，手机和平板居中显示，桌面靠近加号点击位置展开并避让屏幕边缘；加载期间预留完整面板高度。
- 表态详情的「全部」列表每位用户只占一行，按用户现存最早的表态时间从早到晚排列；行内展示该用户的全部表情，按添加时间从左到右排列。「全部」计数为表态总数；单表情标签仅展示添加该表情的用户，按添加时间从早到晚排列。
- 撤回消息从活消息列表直接移除，不留“消息已删除”行；话题根例外：它保留为“消息已删除”墓碑行，话题入口仍可打开，直到话题不再可见（服务端清零 has_thread）。
- 本人资料不只在登录时使用：后续 HTTP/WS 中的最新本人资料更新共享身份，待发消息的用户组、名字、性别、头像随之更新；收藏快照不反向覆盖当前身份。

## 消息转发

- 选择目标会话后跳转到该聊天或话题，将转发内容作为待发送预览放在正常输入框上方；选择目标不会发送请求。预览沿用回复的两行结构：单条上方显示源头发送者（已有转发来源时使用原作者），下方显示内容摘要，不显示转发条数；合并上方显示记录参与者，下方显示“转发 n 条消息”。参与者按所选消息作者 UID 去重并按记录中的出现顺序排列，一人显示用户名，两人显示“user1和user2”，三人及以上显示“user1和其他 n−1 人”。右侧 × 移除转发并保留输入文字。有待转发内容时，空文本也可点击发送；有文字则作为独立附言，在转发成功后发送到同一聊天或话题。转发失败保留附言等待重试，附言失败独立重试，不重复转发；两条消息不保证相邻或一起成功。
- 待转发草稿只保存选定时的服务器消息数据，不持有上传任务或本地文件，不随源消息的编辑、撤回或转码状态更新；实际发送时由服务端校验来源并生成内容。待转发内容按目标聊天／话题隔离，每个目标保留一组，新选择替换旧选择。应用内切换会话后仍保留，刷新或切换账号清除；文字草稿沿用已有持久化规则。聊天及话题列表显示草稿标记和待转发条数；有附言时显示附言，否则单条转发显示消息摘要。待转发草稿隐藏上一条消息的发送者与发送状态，移除后恢复正常消息预览。目标原有文字草稿保留并可作为附言；已有回复和编辑上下文在转发期间暂时隐藏，移除或提交转发后恢复，未完成的编辑文字不被附言覆盖。主动开始另一条回复或编辑会移除待转发内容。转发期间只输入文本附言，暂时隐藏普通附件预览并停用新增附件和贴纸，已有附件仍保留；已开始的录音保持原有操作，可独立发送或取消。

- 消息菜单的“转发”直接打开目标选择；会话页的“多选”选中当前消息并显示勾选、数量、批量撤回、取消与转发操作。系统、已撤回消息及尚未取得服务端消息 ID 的本地消息不参与多选；已经入库的待转码语音、邀请消息和包含多层记录的卡片可选中。勾选时不检查转发资格；点击转发时校验类型与来源是否仍可用，服务端负责最终校验。
- 多选限同一来源聊天、最多 100 条；0 条禁用转发，非空选择可点击转发并触发校验；通过校验后，1 条走单条接口，2–100 条合并为聊天记录。选择数量不影响目标范围，两种方式均支持普通聊天和话题。多选期间点击消息行任意位置只切换选择，包括聊天记录卡片、邀请卡片、引用、话题入口、媒体、文件、链接、头像、表态及重试区域；不可选消息不响应内部操作。保留输入草稿、分页选择和消息 DOM；取消恢复输入栏，离开会话清理选择。
- 话题页在消息总数（含根消息）不超过 100 条时提供整体转发：点击转发图标打开目标选择器，选择目标时重新读取话题当前全部消息，作为目标会话的待转发内容；总数超过 100 条、包含不可转发消息或读取失败时不入队并说明原因。系统消息和已撤回消息不参与整体转发。总数变化后入口随之隐藏。
- 多选底栏左侧为撤回图标，中央显示“n 条消息”，右侧依次为取消、转发图标。仅全部选中消息均可撤回且当前会话可写时启用撤回；确认后将所选消息一次提交批量撤回接口（最多 100 条）；已入库但尚未发布的语音先等待发布，再与其余消息一起提交。等待失败的项保留，其余可提交项仍按一批处理；服务端校验整批后在同一事务中撤回，已撤回项可安全重试，只在服务端确认后计入成功。全部完成退出多选，等待或请求失败时保留未撤回项供重试。处理期间禁用勾选和底栏操作，离开或取消多选后停止发起后续撤回，不改变已完成的结果。
- 目标选择器展示非归档聊天与已订阅的非归档话题，按最近活动混排并分页。搜索过滤已加载目标的聊天名称与话题正文；触底或点击“继续加载”可读取下一页，搜索结果为空或不足一屏时也保留该入口。聊天与话题分别提示加载失败、分别重试，一侧失败不隐藏另一侧已加载的目标或阻断其分页。话题行展示所属聊天和单行根消息摘要，超出宽度省略，不显示回复条数；摘要与头像角标遵循聊天列表的规则。点击目标后关闭选择器并进入目标会话。在目标输入框点击发送即入队并提交转发请求，不额外读取来源状态。后端确认存在待转码语音或合并嵌套超限时，弹窗请求占位替换许可；确认后使用同一操作 ID 重试，取消保留失败任务及尚未发送的附言供重试。来源已撤回或权限失效时转发失败，附言不发送。发送确认及失败状态沿用目标会话的消息队列，见[加载反馈](loading-indicators.md)。
- 单条转发保留正文与媒体类型，发送者为转发人；气泡不显示转发者的用户名、用户组或性别，连续消息首条及菜单弹层预览使用相同规则。气泡依次展示弱化的“转发自 xxx”、只读的原回复摘要和内容。来源标签不链接原消息。回复转发消息时，引用和输入栏标题使用转发来源，但点击引用仍定位当前聊天中的被回复消息。
- 贴纸和聊天记录卡片单独转发不展示额外来源、原回复摘要或来源链；卡片内部原有作者和引用保留。单独转发卡片复用原记录，不增加嵌套层级；包含子记录的卡片与其他消息合并时，经确认替换为不可展开的占位内容。转发文字不可编辑，包括输入框向上编辑入口。
- 合并记录按消息 ID 排序，卡片展示前三条摘要与总数，打开时才读取详情。列表、引用、嵌套记录摘要和通知预览中的类型占位统一显示“[聊天记录]”；卡片与详情页标题显示“聊天记录”。卡片气泡不显示转发者的用户名、用户组或性别，连续消息首条及菜单预览使用相同规则；摘要中的原消息作者仍正常显示。内部引用定位当前记录中的对应消息，外部引用仅显示隐藏提示；不补读源聊天。子记录通过根消息或收藏的授权路径打开，浏览器返回逐层退出。详情以只读话题页面展示，使用会话的整页导航、消息分组、正文与浮动日期、左右气泡和头像偏好；保留图片、语音、嵌套记录和记录内引用的浏览，禁用消息菜单、回复、转发、撤回、表态及头像、用户名、提及的资料跳转。不显示输入栏、话题订阅或会话信息入口。
- `placeholder` 类型的 `pendingAudio` 显示为“[待转码语音]”，`nestedForward` 显示为“[聊天记录]”；正文、菜单预览、引用、聊天记录摘要及详情、收藏和应用内生成的通知均按当前语言显示。普通文本即使与原因代码或占位文案相同也不转换。占位内容没有媒体或子记录，不提供播放、展开、编辑或复制内部原因代码的操作；再次转发沿用占位内容，不重复询问，也不会在源语音转码完成后恢复。未知原因显示本地化的不可用提示。
- 聊天授权的记录详情在根消息撤回或成员权限失效后清除，迟到回包不能恢复失效内容。收藏记录使用收藏授权读取详情，即使来源已删除或不可访问仍可浏览；不提供脱离来源权限的再次转发。打开详情保留底层会话或收藏列表。
- 目标选择器打开后固定本次选择；期间收到所选消息撤回时禁用提交并提示重新选择，不静默改变消息数或发送方式。
- 目标选择器的搜索明确限定已加载目标，尚有未读取目标时使用部分结果空态；更改搜索条件回到结果顶部，同条件续页与后台更新保留阅读位置。按压和滚动期间保持已有目标的顺序，但撤销权限、删除和归档立即移除对应目标。来源读取期间允许取消，关闭开始后及销毁后的迟到结果不再准备草稿或导航。开始路由提交后暂时禁止关闭；导航失败保留选择器、搜索及位置，成功后关闭。

## 输入、草稿与待发队列

- 输入区没有格式工具栏或链接编辑弹层，仅提供 Ctrl/Cmd+B 加粗和 Ctrl/Cmd+I 斜体快捷键，分别使用双星号和双下划线。快捷键将选区两端空白放在标记外，跨空行的选区逐段包裹，保留段落分隔；无选区时不插入标记，IME 组字期间不处理格式快捷键。

- 输入栏共用一个圆角边框，内部左侧为回形针附件按钮，点击保持输入框当前焦点和键盘状态，直接向上弹出与标题操作菜单同样式的纵向菜单，可选择媒体（图片或视频）或文件；点选媒体或文件后关闭菜单并释放输入焦点；Android 上从输入状态选择时先让键盘收起、页面尺寸稳定，再打开系统选择器，返回时不自动唤起键盘；输入框内右侧为贴纸按钮，下方展开贴纸面板；圆角边框内部右侧为录音或发送按钮。输入垂直居中，飞机图标向右作小幅视觉偏移。
- Windows 贴纸按钮 hover 提示 `Emoji: Win + .`，macOS 提示 `Emoji: fn + E`。
- 桌面 Enter 发送、Shift+Enter 换行；移动系统 Enter 换行。IME 组字期间不发送，提及候选的 Enter 优先选择候选；空输入向上编辑上一条自己的文字消息，Esc 取消回复或未改动的编辑。
- 可拖入、粘贴附件；仅群聊及其话题可选择提及，私聊及其话题输入 `@` 不查询成员或弹出候选框。文件拖入输入栏时高亮可放置区域，拖过内部控件不闪烁；移出、取消或放下后恢复，普通文字拖动不触发附件高亮。不因为消息读取、发送、编辑请求或附件上传而禁用输入；不发送空内容。已知私聊不可发送时，点击提交说明原因并保留文字、附件、录音；关系未知时由服务器判断。
- 离开/切换会话、切后台、pagehide 时保存文本、回复 ID 和时间；不边输入边写草稿。相同内容不重复保存，空草稿删除。编辑文本独立于普通草稿。
- 提交入队即清空对应输入与草稿，迟到确认不能清除后续输入。文件、语音、贴纸独立发送时保留其他未提交内容。

| 队列情形             | 必须保留的行为                                                                                   |
| -------------------- | ------------------------------------------------------------------------------------------------ |
| 点击发送             | 立即上屏，排在已存在消息后；保留稳定 clientGeneratedId，确认回声更新同一行                       |
| 同一会话连续发送     | 准备好的消息串行发出并等待确认，避免顺序倒置；不同聊天/话题独立                                  |
| 附件压缩或上传中     | 可以立即提交并移交任务，附件在气泡上继续显示 progress spinner；不占发送槽，不阻塞后续聊天        |
| 附件失败             | 提交前禁用发送；入队后任一附件失败立即标记整条失败，重试整条时一起重试失败附件并复用已成功附件   |
| 附件准备完成         | 进入普通发送流程，可以像文字一样等待前一条确认、阻塞后一条提交                                   |
| 刚提交就编辑         | 未发请求直接改待发内容；已发请求先取得服务器 ID，再提交编辑。取消编辑不取消队列借出的上传任务    |
| 刚提交就撤回         | 立即隐藏并停止创建重试；未发请求直接移除，已发请求保留撤回意图，取得 ID 后补撤回                 |
| 请求失败             | 显示失败图标，后续消息继续；断网恢复/重连可重试，创建重试保持原 clientGeneratedId 和已发请求内容 |
| 上传取消             | 撤回或移除附件取消处理/上传、释放文件和本地 URL；浏览器不可取消的编码完成后丢弃结果，不继续上传  |
| 语音已确认但尚未发布 | 保留确认与本地播放；转码期间 GET 404 不重新创建消息                                              |

发送状态位于时间之后：`cloud-upload-outline` 上传，`time-outline` 排队/发送，`checkmark-outline` 服务器确认，`checkmark-done-outline` 表示对方已读，`alert-circle-outline` 失败。已读仅显示在当前普通私聊或其对应话题范围内、本人已确认且不晚于服务端授权回执的消息；群组、置顶和搜索结果始终不显示已读。列表预览中本人发送的最后一条非系统、未撤回消息在时间左侧按同一发送状态图标显示发送中、已发送或已读：待发队列决定前两者，已读仅用于私聊且使用同一授权回执。草稿替代消息预览时不显示发送状态。确认勾不带圆圈。

队列只在本次应用内存中跨页面存活，整页刷新/关闭不恢复。协议不能按 clientGeneratedId 查找或撤回：不判断确认是否“彻底丢失”，用户撤回时就隐藏；之后靠正常读取、推送或迟到回包尽力取得 ID，不扫描历史兜底。

### 已读回执

- 设置 → 隐私中的“已读回执”为开关，默认开启，切换即保存；当前好友资料提供使用全局设置、分享、隐藏，选择后立即保存。回执遵循双向分享、好友关系与拉黑限制；解除好友时覆盖值删除。
- 普通私聊及私聊话题分别读取其独立的对方已读高水位；话题页中的根消息仍使用普通私聊回执，回复只使用该话题回执。回执只向前推进，标记未读或删除消息不会使其后退；不显示时间，不从本地未读位置或其他范围推断。服务端授权结果缺失时显示单勾。

## 媒体与录音

- 照片方式及粘贴、拖入的媒体自动尝试压缩，文件方式保留原字节。静态图片兼顾普通照片与长截图的清晰度，保持比例、不放大、不裁剪，编码不得丢失透明度。保护动图，必要时解码 HEIC；无法有效压缩时回退原文件，参数见[媒体数据流](data-flow.md#媒体与语音)。
- 附件选择后即可开始处理；发送后任务归队列所有。录音保存先留本地 Blob，明确发送才上传。
- 支持录音（包括待授权）显示 `mic-outline`，不支持显示 `mic-off-outline`；两者都可点，不支持时显示 IonAlert。录音期间通过录音操作区保存、发送或取消，不同时提交普通文本。
- 语音使用 WaveSurfer.js 波形播放器，包含圆形播放/暂停、波形拖动、时长，不使用原生音频控制条。挂载即加载音频，同时只播放一条，切换会话不打断播放；消息语音播放时吸顶显示在主栏 header 底部（会话页与聊天列表页，桌面分栏时在会话列顶部而不在侧栏）（播放/暂停、发送者名与时间跳转原消息、已播时长与全局倍速），波形读取失败不妨碍可用播放；无文字说明时时间戳以无底色文本叠加在条内时间行右端。
- 媒体打开为全屏遮罩，顶部不留空横条，右上控制浮动。底部 gallery 只切换**同一消息**的图片/视频；支持捏合、滚轮缩放、放大拖动、方向键与浏览器全屏。
- 贴纸面板支持收藏、订阅、创建包、向自己的包上传图片/WebM；包列表按用户贴纸包顺序排序，开启自动整理后发送贴纸为所属包记录使用时间，仅统计排序后前 20 个包。点击消息贴纸打开所属包详情，默认选中该贴纸，点击其他贴纸只切换选中项。底部提供“收藏单个 / 取消收藏”和“订阅整组 / 取消订阅”，取消操作使用 danger 色。详情标题为包名，第二行显示包内贴纸数量。贴纸属于多个包时默认打开返回的第一个包并保留包切换；无所属包时允许单独收藏，禁用订阅。

## 信息、群组、好友与搜索

- 信息头部复用列表头像和话题角标，头像、标题居中，标题最多三行；群简介、用户组和话题所属聊天显示在标题下的小字区域，不显示 UID。右上角关闭按钮为 44px 点击区域、28px 图标。会话 toolbar 的标题左侧显示 32px 头像。
- 群信息显示搜索、静音、退群；管理员额外显示独立邀请按钮，没有更多菜单。话题只显示搜索和订阅/归档，没有更多、群编辑、邀请、退群或聊天收藏入口。静音时显示时长，永久只显示“永久”。
- 群管理员可在名称和简介旁点击铅笔，在原位置编辑现有文字，点击对勾仅保存该字段；名称不能为空，简介可清空。保存失败显示 toast 并保留输入，切换会话丢弃未保存的编辑。头像显示相机角标，点击选择图片，上传时头像内显示进度环，成功后更新。普通成员仅查看资料；不提供群可见性编辑。
- 用户资料弹窗与私聊侧栏共用 ChatDetails，无 toolbar。按钮依次为个人空间、添加好友（非好友）或发消息（好友且不是当前会话的信息面板）、搜索、静音、解除好友（好友）、拉黑/解除拉黑。当前会话的信息 modal 同样隐藏发消息；自己的资料仅显示个人空间。没有可访问会话 ID 时搜索、静音不可用。添加好友的验证方式在点击后读取，确认弹窗内填写验证信息。
- 话题信息区显示“xxx 中的话题”，订阅与归档共用一个按钮：未订阅显示空心铃铛及“订阅”，已订阅显示空心归档及“归档”，已归档显示实心归档及“已归档”，点击取消归档。操作及状态刷新期间保留已知状态文字，不将暂时缺失的状态当成未订阅；不显示退群或删除好友按钮。
- 基础资料已有缓存时立即显示；详情、好友关系或媒体请求不能让整个信息头部变成 spinner。
- 信息标签依次为话题、成员、图片、视频、文件；普通私聊没有成员，话题没有话题标签。打开会话默认第一页，只有选中标签加载。话题成员显示参与者：优先使用话题列表缓存中的完整名单，并合并已加载回复；没有缓存时仅从话题根与已加载消息提取，明确标注范围，不扫描历史或显示所属群成员。图片、视频、文件按所属聊天查询，现有接口不能单独限定话题。
- 搜索与静音入口位于会话标题栏，资料页不显示这两个操作；话题保留订阅/归档按钮，不显示静音。个人资料按钮单行排列，群邀请排在退群前面。
- 信息头部保留背景色区域的留白；标签上方没有额外白色间隔块或标题。
- 成员页没有搜索条和右侧互动按钮，点击行打开资料，右侧只有管理员显示“管理员”。
- 群成员、媒体和聊天搜索使用与 ChatList 相同的 Ionic 无限滚动。话题从普通消息页筛选根消息，游标来自原响应；一页没有话题不意味着结束，也不能为了填满首屏循环扫描历史。加载控件不可点击。
- 话题会话标题与列表预览一致；右侧未订阅显示空心铃铛，已订阅提供归档/取消归档（空心/实心归档图标）。不恢复列表话题的三头像预览。
- 置顶在会话 toolbar 下方显示预览栏，点击定位并轮换，另有完整置顶列表。主 toolbar 底边始终存在。置顶共享活消息，收藏保存快照；两类页面复用 Message 样式，不把静态集合强塞进 ConversationPage。完整置顶列表的背景与浮动日期沿用会话的行为（见会话章节），不在页面内重复实现。收藏仅保留全局入口，不提供本聊天收藏或其专用路由。被撤回的置顶仅在消息仍可见（话题根）时保留并可定位，其余不再出现在预览栏和置顶列表中。
- 保留创建/加入群、编辑群资料、邀请管理、好友申请/接受/拒绝/归档、删除/拉黑、用户资料和论坛链接。权限决定可用操作；邀请预览不自动入群。
- 聊天内全文搜索支持相关度/最新排序；媒体汇总按图片/视频/文件分类，定位消息时进入其所属话题。全局历史搜索、按发送者/日期筛选、独立全量群话题列表无协议支持，不增加客户端全量扫描。

### 在线状态与最近上线

- 私聊会话标题和用户资料显示个人状态：有任意一条有效 active WebSocket 连接显示“在线”；所有有效连接都为 inactive 时显示“离开”，无绿色在线圆点。页面隐藏或窗口失焦上报 inactive。没有有效连接时显示最近上线时间。多设备、多标签页按用户合并，active 优先。
- 设置中的“在线状态隐私”控制个人在线状态与最近上线时间：全局可选所有人、仅好友、没有人，新老用户默认所有人；更改后点击保存。当前好友的资料（侧栏或 modal）提供使用全局设置、分享、隐藏，选择后立即保存，覆盖本人的全局策略；失败恢复原选择。解除好友删除双方覆盖值，重新添加后使用全局设置。
- 个人状态遵循双向分享：只有双方都允许向对方分享才显示精确时间、在线或离开状态；任何一方隐藏，双方只看到后端返回的四档模糊时间，私聊绿点同步受限。全局策略不扩大已有查看权限，不绕过任一方向的拉黑；可查询范围内任一方向拉黑时后端固定返回 longAgo，不返回精确时间或 away；范围外仍不返回状态。范围限于本人、好友或共同普通群成员，仅有历史私聊不授予查看权限；模糊时间不表示用户离线。
- 普通会话标题的名称与在线/最近上线状态使用独立的上下两行，状态不继承名称的加粗样式；群人数使用同一状态行。会话标题和资料中的状态行始终保留高度，包括加载、未知与无权查看时，避免回包后布局跳动；加载反馈见[加载与操作反馈](loading-indicators.md)。
- 在线优先显示“在线”；离线时使用已有 `user_extra.last_seen_at` 显示最近活动时间，不新增断线时间记录。该字段来自 HTTP 请求和 WS 心跳（包括 inactive 心跳），共用每客户端 5 分钟写入节流；它不是精确断线时间或前台离开时间。
- 允许查看精确时间时，按 Telegram Web A 的近期时间规则显示：少于 1 分钟“刚刚上线”、少于 1 小时“最近上线于 N 分钟前”、少于 12 小时“最近上线于 N 小时前”，分钟和小时向下取整；之后显示“最近上线于今天 HH:mm”“最近上线于昨天 HH:mm”或日期及时间。今年的日期省略年份，其他年份保留年份；使用本地时区，随应用语言变化，跨日与跨年按本地日历判断。
- 隐私隐藏时只展示服务端的四档枚举，不接收或保留精确时间：少于 3 天“最近上线”、3–7 天“一周内上线”、7–30 天“一个月内上线”、30 天及以上“很久没上线”。隐藏但存在有效 active 或 inactive 连接时均返回“最近上线”，不透露离开状态。为兼容旧后端，连接正常且加载结束后，未返回个人状态或缺少活动时间时显示“很久没上线”；首次加载仍显示线框，实际断网、页面未激活或 UID 缺失时不显示兜底文案。

- 群会话标题和群资料显示当前成员总数及在线成员数；在线人数是当前成员中在应用任意位置保持有效连接的去重用户数，包含离开状态，不是当前阅读群聊的人数，也不由已加载成员分页计算；不受个人在线隐私设置影响。话题参与者不显示为群成员统计。
- 连接正常时，切换分类、重新订阅、后台刷新和恢复可见保留已知状态，新授权结果到达后原位更新；不先隐藏绿点、清空状态行或把已有状态替换为加载线框。只有尚无数据的状态显示[加载占位](loading-indicators.md)。
- 本机实际断网、WebSocket 断开或账号切换时，不显示缓存的在线断言或在线人数，不把其他用户判为离线；成员总数可保留。请求与可见页面订阅生命周期见[数据流](data-flow.md)。

## 通知、静音与设置

- 开发模式自动启用仅处理通知的 Worker，不注册资源请求处理器、不加载 Angular 缓存模块；支持通知权限、前后台通知和点击定位，需可信 HTTPS 或 localhost。开发模式不提供应用版本更新检查。生产构建保留 Angular 资源缓存与更新行为。

- 在线 WebSocket 优先处理通知，页面未运行时由 Web Push 兜底。前后台页面均交给 Worker 展示系统通知；推送注册失败不阻止已经获得授权的在线提醒。
- 支持通知且启用 Worker 的环境，登录进入应用且本机没有通知选择时，已获浏览器授权则直接继承开启并后台登记订阅；尚未授权时显示标题 `允许“茶话”发送通知吗`、说明 `以后可以在设置内修改` 的 Ionic alert。不允许立即关闭并记住选择；允许按钮显示 spinner，授权和推送注册成功后关闭，失败显示“授权失败，请再试一次”的 toast 并保留弹窗供重试。
- 通知设置同步读取环境、本机 `chahua.notifications.enabled` 和浏览器权限。不支持时不继续检查；本机关闭时不请求授权。进入设置不自动请求权限，缺授权就保存为关闭；设置首页的消息通知行仅打开独立子页；子页始终显示本机通知开关，未授权或环境不支持时禁用。支持通知且未授权时另显示申请权限按钮，直接点击请求浏览器权限，授权后隐藏按钮。
- 已授权且本机开启时，异步确保浏览器订阅与后端登记；后台检查不显示 spinner、不禁用开关，失败静默等待下一次检查。注册失败但权限仍在时保留开启选择；用户主动操作才显示等待和失败反馈；等待时禁用通知开关与申请按钮，在开关旁显示 spinner，权限被拒绝使用 toast，不在设置行内显示拒绝文案。关闭立即停止本机提醒，并尽力删除后端登记、取消浏览器订阅。
- 各平台、各分栏布局统一使用系统通知，需要本机开启通知并获得浏览器授权。正在前台阅读对应会话不提醒；设置或 modal 覆盖会话时仍提醒。
- 通知规则遵循现有协议：自己、系统和已撤回消息不提醒；提及、回复自己、聊天归档、话题订阅/归档的优先关系见[通知数据流](data-flow.md#通知与静音)。通知点击复用应用并定位消息，不能重载丢失待发队列。
- 去重、已读清理和撤回清理在独立 IndexedDB 中保存按账号隔离的有限期通知记录，不保存消息正文。系统角标保留账号级未读总数。后台标题在会话页显示该会话（话题）的未读消息数，在其他页面显示当前 tab badge 的未静音未读会话数；任一 tab 显示 mention 或所在会话有未读 mention 时标题只显示 `(@)`，mention 优先于数字，计数达 1000 显示 `(999+)`，回到前台恢复应用标题。进入会话或设置时保留最近选择的 tab，分栏以侧栏选择为准。普通 tab 不包含归档，归档入口只统计对应归档集合；系统通知不随 tab 切换。
- 静音提供 1 小时、8 小时、1 天、7 天、永久；到期自动更新标志。取消静音按现有协议同时取消归档，不增加跨设备静音/已读轮询。
- 更新检查独立于 Angular 启动与登录；启动失败、登录等待、landing 或 418 中，新版资源完整下载后自动刷新。已登录业务页面渲染后显示更新 toast，用户选择“立即更新”才刷新；“暂不更新”保留页面、草稿和待发任务，同一版本在本次页面会话内不再提示，设置页仍可立即更新。
- 设置为大头像和居中名字；各列表项有图标，依次为消息通知、隐私、聊天设置、贴纸和表情、语言，分组间隔后为检查更新。隐私首页按顺序显示已拉黑用户、加我好友时的验证方式、谁能查看我的活动状态、已读回执；右侧小字显示实际拉黑人数（零为“无”）、当前验证方式、活动状态可见范围和已读回执开关状态。四项分别打开拉黑列表、好友验证、在线状态和已读回执详情。好友验证的非问题模式和活动状态详情切换选项即保存；“需要回答问题”模式显示“应用”按钮，输入有效问题后点击应用才保存，切换到该模式或结束输入不自动保存。保存期间暂时禁用编辑，失败保留当前选择并提供重试。拉黑列表可进入用户资料管理拉黑状态；从详情返回首页时重新读取当前摘要，加载中不显示默认值，失败提供重试。聊天设置提供颜色模式、消息字号及显示话题、全部头像、私聊头像和用户名三个开关。消息字号沿用五档：12px、14px、系统默认、18px、20px，默认保留当前平台字号，即时应用并保存本机；显示当前字号或“系统默认”，预览区域保留最小高度。消息通知首页只有导航入口；通知子页不支持时显示“不支持”说明；检查更新只有一行，不支持置灰，前面留间隔。没有退出登录按钮。检查更新行显示完整构建版本，与 API 请求携带的版本一致。
- 设置首页提供语言选择，可选自动、English、简体中文和繁體中文，默认自动。自动模式按浏览器语言精确匹配后按语言/文字匹配，无法匹配时使用英语；选择只保存在本机，切换后界面文案立即更新并同步 `document.documentElement.lang`。界面文案由 `src/i18n` 的 catalog 提供，后端返回的系统消息和错误文本不随界面语言变化。
- 聊天设置提供颜色模式，可选跟随系统、浅色和深色，默认跟随系统。选择只保存在本机，切换后立即作用于整个应用，包括工具栏、内容背景和原生控件配色；跟随系统时随系统深浅实时变化，启动阶段在 Angular 挂载前就应用，避免闪烁。
- 设置列表提供「表情和贴纸」入口。子页可编辑置顶表态表情（默认 👍，最多 5 个，去重，保存在本机，可用输入或表情选择器追加），提供两个只保存在本机的自动整理开关和创建贴纸包入口；自有与订阅贴纸包合并为一张列表，按最近使用排序并标记自有包。拖拽重排写入与相邻包的中点使用时间并同步服务器，成功后进入包详情页。开启自动整理且贴纸包超过 20 个时，第 20 行之后显示分隔线，分隔线以下不参与自动排序。包详情页对自有包提供重命名、删除和添加/点按移除贴纸，对订阅包提供取消订阅；删除与取消订阅会从排序列表移除该包并返回上一页。
- 深浅色均适配，toolbar 背景延伸至系统顶部。原生悬浮滚动条可用时保持原生，否则使用 OverlayScrollbars，不占内容宽度。

## 验证约束

测试使用 mock HTTP、WebSocket 和上传。禁止向生产服写测试数据，禁止测试上传 S3；必须实测写入时使用本地后端与开发数据库，账号也只在开发环境创建。开发默认代理仍指向生产环境，不能把访问 localhost 等同于后端安全隔离。

通知权限被拒绝时显示浏览器网站设置指引，返回页面或重新获得焦点时刷新权限；通知服务或订阅失败提供明确说明与重试。语言包加载成功后才保存语言选择；失败保留原语言并允许重试，迟到的旧请求不覆盖新选择。贴纸创建、管理与排序写入期间提供等待反馈并限制重复操作；排序保存失败可重试原操作。

## 即时操作与消息细节

- 静音、聊天与话题归档、话题订阅、贴纸收藏／订阅以及取消消息收藏立即更新界面；请求失败恢复原状态。贴纸包顺序更新立即生效，排序同步失败时以重新读取的服务器顺序为准。较早请求失败不能覆盖较新的选择或推送。未读汇总仍以服务器结果为准。
- 收藏快照每行的“查看原消息”和“取消收藏”放在右键／长按菜单中；无法定位的快照禁用查看原消息。
- 连续消息组越过窗口底部时，在发送方一侧固定显示头像；原头像进入视口后接替固定头像。合并转发聊天记录沿用此行为，并遵循“每条消息旁都有头像”设置，不受私聊隐藏头像设置影响。占位头像按名称哈希选取同一套明暗主题颜色。
- 回复与列表摘要同时展示附件类型和文字说明，保留提及名称；编辑动作使用 `create-outline`。
- 贴纸菜单预览保留透明背景，不加普通气泡或作者标题。贴纸消息菜单提供回复、转发、多选、收藏表情、复制链接，以及本人或管理员可用的撤回；不提供表态、话题、置顶或消息收藏。
