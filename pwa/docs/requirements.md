# 产品需求与边界

本文列出客户端当前遵循的需求。组件与状态归属见 [Components](components.md) 和 [数据流](data-flow.md)，外观依据见 [外观](appearance.md)。

| 范围       | 当前行为                                                                                                                                                         |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 协议       | 使用既有后端协议与生成模型；不为展示补新接口。Snowflake ID 使用无损 number 编码，null/undefined 不做全量转换。                                                   |
| 启动       | URL token、浏览器保存的 token、开发预设依次优先。登录与启动只显示同一外观的 spinner，不附加载文字或虚构 toolbar。                                                |
| 页面加载   | 所有路由静态导入。第三方表情、编解码等较大功能可以按使用时机加载。                                                                                               |
| 分栏       | md（768px）出现聊天列表侧栏；xl（1200px）出现可收起的 360px 信息栏。较小屏幕的信息内容通过 modal 打开，两种信息容器都没有 toolbar。                              |
| 列表导航   | 单列使用路由；分栏时分类、归档切换仅改变左侧选择，保留右侧会话。切 tab 的入场动画只作用于列表内容。设置通过浏览器历史关闭，不误操作底层列表。                    |
| 列表顺序   | 消息 tab 开启话题时，只显示两种来源共同覆盖的时间范围。关闭该选项，以及群组、好友、话题独立 tab 均独立分页。                                                     |
| 固定入口   | 已归档、好友请求历史入口常驻，历史内容按需读取。归档数使用后端返回的总数，颜色为灰色，不为分群组/好友计数遍历归档记录。                                          |
| 阅读       | 有较长未读区间时打开未读边界，短尾部直接到底；引用与置顶可定位原消息，下箭头返回引用来源或最新位置。                                                             |
| 滚动       | 普通 DOM 分页、边缘预取、惯性停止后合并历史；以可见消息底部为锚，资源加载前预留尺寸。重连至多补一页，其余通过正常分页恢复。                                      |
| 消息外观   | 连续作者紧凑分组；只有头像打开用户资料。消息气泡内的引用有作者色边线与背景；回复输入栏采用紧凑灰底、primary 竖线和“正在回复 xxx”。                               |
| 输入       | 附件加号在框外，照片/文件面板在下方；贴纸按钮在框内，录音在框外。输入和提交不等待消息历史加载。无内容不发送空消息。                                              |
| 草稿       | 离开、切换会话和页面隐藏时保存文本及回复目标；不在每次输入时写入草稿或改变列表排序。                                                                             |
| 媒体准备   | 照片方式发送的图片/视频压缩，文件方式保持原文件；保护动图，处理 HEIC，无法压缩时保留可发送的原文件。                                                             |
| 待发队列   | 立即上屏；正在上传的附件不阻塞后续文字，上传完成后进入同一发送顺序。发送失败允许下一条继续，网络恢复可重试。                                                     |
| 编辑与撤回 | 刚提交即可编辑和撤回。未开始发送直接移除；已开始发送先隐藏并停止重试，取得服务器 ID 后尽力补撤回。不显示撤回占位消息。                                           |
| 取消附件   | 撤回和移除附件会取消压缩、上传并释放临时资源；任务移交给队列后不占用输入框。                                                                                     |
| 状态图标   | cloud-upload-outline 为上传；time-outline 为排队/发送；checkmark-outline 为确认；alert-circle-outline 为失败。                                                   |
| 录音       | 支持及待授权时显示 mic-outline，不支持显示 mic-off-outline；仍可点击查看 IonAlert。手势支持保存、发送和取消。                                                    |
| 消息操作   | 桌面 hover 显示回复按钮；手机左滑显示填充与放大反馈。长按/右键展示表态及菜单，撤回使用红色。表态显示用户头像，可查看按表情分类的完整名单；最近表情跨会话保存。   |
| 置顶与收藏 | 置顶在 toolbar 下方显示预览，点击定位并轮换。置顶共享活消息集合，收藏持有快照；两者复用普通消息样式。                                                            |
| 全屏媒体   | 顶部按钮浮动，没有预留横条；同一条消息内的多媒体通过底部 gallery 切换；连续捏合/滚轮缩放、放大拖动、方向键和浏览器全屏可用。                                     |
| 信息内容   | 头像、标题及操作在上方；更多使用下拉。群聊下方依次为话题、成员、图片、视频、文件，按需读取。私聊为话题、图片、视频、文件；话题仅图片、视频、文件。默认选第一页。 |
| 群组和好友 | 创建/加入群、群资料、成员和邀请管理；好友请求、接受/拒绝/归档、删除/拉黑及资料入口依照权限展示。                                                                 |
| 搜索       | 聊天列表加号中的搜索切换 toolbar 为搜索条，搜索群和用户；聊天内全文搜索支持相关度/最新排序。媒体汇总按图片/视频/文件分类。                                       |
| 系统消息   | 固定后端短语作为枚举渲染成中文，包含真实用户名；列表里的系统行为为主题蓝色，用户正文为灰色。                                                                     |
| 本人资料   | 登录补齐用户组；后续 HTTP 和 WebSocket 中的最新本人资料更新共享身份，待发消息随之更新。                                                                          |
| 通知与静音 | 在线处理优先，Push 兜底。只有单列布局展示顶部应用内通知；双列/三列仍处理后台系统通知。时长静音、归档和提及例外遵循协议。                                         |
| 设置       | 大头像和居中名字，列表有图标；通知与检查更新各一行，无退出按钮。通知不支持时展示“不支持”，检查更新不支持时置灰。                                                 |
| 平台样式   | 明暗主题、系统顶部背景延伸和 Ionic spinner；原生悬浮滚动条可用时保留原生，否则使用 OverlayScrollbars。                                                           |

- `/landing` 保留旧版五个平台的安装指引、文案和样式；已安装应用直接进入聊天。多语言与主动添加群成员不提供。
- 语音使用 WaveSurfer.js 波形播放器，包含圆形播放/暂停、波形拖动、时长和倍速；点击播放才读取音频，不使用原生音频控制条。
- 输入支持拖入文件、提及候选键盘选择、空输入向上编辑上一条自己的文字消息，以及 Esc 取消回复或未改动的编辑。私聊关系明确不可发送时说明原因并保留输入与附件。
- 贴纸面板可创建包、向自己的包上传图片或 WebM；不添加设置入口。用户资料提供论坛空间及本人修改名字、头像链接。
- 重连期间 toolbar 显示 spinner；后台浏览器标题显示后端未读总数；滚动消息时顶部浮动显示当前日期。

## 协议与一致性边界

- 全局历史消息搜索、按发送者/日期筛选和未读表态导航没有对应查询能力；群与用户搜索不等同于全局消息搜索。
- 群内话题没有独立全量列表接口，逐页读取群消息筛选根消息，可以包含未订阅的话题，首屏不足一屏时继续读取，之后滚动续页；只有当前标签有消费者时读取。
- 发送确认完全丢失时，协议不能按 clientGeneratedId 查询/撤回；队列等正常读取、迟到响应或推送取得 ID 后补撤回。
- 已提交队列保存在本次应用内存中，跨页面存活；关闭或刷新应用不提供持久化待发恢复。草稿只保存文字和回复 ID。
- 重连不建立全量补偿日志。重复事件去重与正在请求时的补丁负责局部一致性，历史缺口通过普通分页处理。
- 系统通知去重是有界内存与通知中心恢复，不维护额外的消息数据库。

## 验证环境

自动化交互使用 mock HTTP/WebSocket。生产服务禁止写测试数据，S3 禁止测试上传；必须实测写入时使用本地后端和开发数据库。
