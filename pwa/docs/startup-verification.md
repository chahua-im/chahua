# 启动页面手动验证

在 `pwa` 目录运行：

```sh
npm run preview:startup-failures
```

默认监听 `0.0.0.0:14310`。本机打开 `http://localhost:14310`，局域网设备打开启动日志中的 `LAN` 地址（`http://电脑的局域网IP:14310`），点击场景即可查看实际生产构建中的页面。端口被占用时会显示说明，可先停止已有服务，或用 `PORT=14311 npm run preview:startup-failures` 换端口。仅需本机访问时可用 `HOST=127.0.0.1 npm run preview:startup-failures`。

模拟服务支持局域网访问，全部 API 由本地处理，不代理真实后端。它在该预览源写入虚构凭证和中文语言偏好，并关闭通知提示；应用构建中没有模拟入口。Service Worker 缓存和版本更新在模拟服务中禁用。需要更改代码后查看结果时，停止服务并重新执行命令以重新构建。

每次只查看一个场景，使用浏览器返回回到场景列表后切换；场景使用同源 Cookie，因此多个标签页会共享选择。直接刷新会重新设置该场景的虚构身份。

| 场景                  | 预期结果与检查                                                                                                            |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| 没有登录信息          | 显示“请重新进入茶话”，文字建议前往发布帖；没有登录跳转或重试按钮。                                                        |
| 登录状态失效（401）   | 显示“登录状态已失效”，建议前往发布帖重新进入；没有跳转按钮。开发者工具中 `jwt_token` 的 localStorage 和 Cookie 均已清除。 |
| 连接失败              | 显示“暂时无法连接茶话”，只提供“重试”；凭证保留。                                                                  |
| 服务暂时不可用（503） | 显示“茶话暂时不可用”，可重试；凭证保留。                                                                                  |
| 其它登录错误（403）   | 显示“暂时无法进入茶话”，不把未知错误断言为网络故障或登录失效。                                                            |
| 连接缓慢              | 先只显示茶话图标和 spinner；10 秒后变为“连接比平时慢”并提供重新加载；15 秒后显示服务暂时不可用。                                |
| 登录超时              | 10 秒后显示慢连接提示；30 秒后显示连接失败／超时，可点击重试。Network 中原请求已取消，不会在后台继续更新身份。            |
| 首次 503，重试后成功  | 点击“重试”后出现聊天框架。只模拟登录成功，后续列表等业务接口仍返回错误，不属于本项检查范围。                              |
| 主脚本加载失败        | 显示“应用加载遇到问题”和“重新加载”，即使 Angular 没有执行仍可操作。                                                           |
| 主脚本一直未返回      | 显示静态启动占位；10 秒后显示“加载时间较长”和“重新加载”。                                                                 |
| 语言包加载失败        | 当前语言和回退语言均失败后，显示 HTML 自带的“应用加载遇到问题”；不显示翻译键或空白页。                                        |
| 安装指引页            | 有凭证时仍显示现有安装指引；不自动发起登录请求。                                                                          |

所有启动状态均显示茶话图标，每个状态最多一个恢复按钮。登录请求失败只提供“重试”；应用启动失败或等待较长时提供“重新加载”，说明会重新加载整个应用。

同时检查窄屏和桌面宽度，以及系统深浅色。未登录页面不能出现聊天列表或发送入口；普通失败点击重试期间不应叠加请求。

预览期间控制台出现对应的 401／403／503、资源加载失败日志属于模拟结果。按 `Ctrl+C` 停止服务。

## 启动文案

固定文案在 `src/i18n/*.json` 的 `app.entry` 中。HTML 的启动文案由这些文件生成，避免依赖尚未加载的脚本和语言包。修改 `boot`、`bootSlow`、`bootFailed`、`reload` 后运行：

```sh
npm run startup:copy
npm run test:pwa
```

测试会检查内嵌文案与语言文件一致。
